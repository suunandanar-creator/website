## 🚀 GitHub Pages Setup

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md`.
3. Add the profile image as `profile-photo.jpg`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save the settings.
7. GitHub will provide the published portfolio URL.

## 🖼️ Add Your Photo

Place the photo in the repository root:

```text
profile-photo.jpg
```

The existing HTML already references this filename.

For best results, use a professional portrait with a vertical or square crop and good lighting.

## 🔗 Add LinkedIn

The LinkedIn button currently contains a placeholder action.

Find this section in `index.html`:

```html
<a class="btn secondary" href="#" onclick="alert('Replace this # with your LinkedIn profile URL.');return false;">LinkedIn ↗</a>
```

Replace `#` with the actual LinkedIn profile URL.
